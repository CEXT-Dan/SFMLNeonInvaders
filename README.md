# SFML Neon Invaders

A Retro Space Invaders in C++ & SFML!

This started out as a test for Qwen3.8-27B Q4_k, the prompt was something like, create a cool space invaders game. The output was HTML/and JavaScript. The original source is in the resources folder

I ported it to SFML, also with the help of Qwen so I could better understand the source.
